## 🔧 Bug fixes / correctness
- **Import paths fixed repo-wide** — `crud/`, `models/`, `routers/` were using bare `from models.X import ...` / `from schema.X import ...`, which would fail at runtime. All switched to absolute `app.models.X` / `app.schema.X` imports (client.py, order.py, product.py in crud; client.py, order.py in models; orders.py, products.py in routers).
- **`products.py` router decorator bug** — `router.get(...)` was called but never applied as a decorator (missing `@`), so `list_products` wasn't actually registered as a route. Fixed to `@router.get(...)`.
- **`Order` model tablename bug** — `__tablename__="orders"` was (incorrectly) passed as a class *keyword argument* to `SQLModel`; moved to a proper class attribute.
- **Naming consistency: `user_id` → `client_id`** — `Order` model and `OrderBase`/`OrderUpdate` schemas renamed `user_id` to `client_id` to match the actual FK relationship to `Client`.
